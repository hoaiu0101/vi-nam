# Ôn thi Ký sinh trùng & Vi nấm học (Thầy Thạnh)

Trang web ôn tập trắc nghiệm tương tự [Hoaiuhocbai](https://hoaiu0101.github.io/Hoaiuhocbai/), dành cho bộ câu hỏi **Ký sinh trùng (Sán lá & Giun)** và **Vi nấm học**.

- **47 câu** chia 2 chủ đề
- Chế độ: Tổng quan · Luyện tập · Thi thử · Flashcard · Ôn câu sai
- Tiến độ lưu trên trình duyệt (LocalStorage), có xuất CSV / sao lưu JSON

## Xem nhanh

Mở file `index.html` bằng trình duyệt, hoặc deploy GitHub Pages.

## Deploy GitHub Pages

1. Tạo repo mới trên GitHub (ví dụ `kst-vinam` hoặc `username.github.io`).
2. Upload toàn bộ nội dung thư mục này (ít nhất `index.html`).
3. Vào **Settings → Pages → Source**: chọn branch `main` (hoặc `master`), folder `/ (root)`.
4. Sau vài phút trang sẽ có tại:
   - `https://<username>.github.io/<repo>/`
   - hoặc `https://<username>.github.io/` nếu dùng repo `username.github.io`.

## Nguồn câu hỏi

Nội dung lấy từ file ôn tập **TN KST Vi Nấm (thầy Thạnh)** do người dùng cung cấp. Đáp án giữ nguyên theo đề; một số câu có ghi chú giải thích thêm.

## Ghi chú

- Không cần build / không cần server — chỉ cần file tĩnh.
- Dữ liệu tiến độ chỉ lưu trên thiết bị đang dùng. Dùng nút **Sao lưu (JSON)** để chuyển máy.
